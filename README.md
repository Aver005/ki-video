# ki-video

Редактор вертикальных роликов для одного сценария: взять горизонтальные записи ShadowPlay,
выбрать окно 9:16, задать панораму и зум ключевыми кадрами, подправить цвет, почистить звук,
наложить текст и субтитры, отдать H.264/H.265.

Техно-демо. Интерфейс в браузере, сервер на Bun, вся обработка видео через ffmpeg.

## Что умеет

- Импорт файлов: видео, картинки и звук — системный диалог Windows (PowerShell), путь вручную
  или просмотр папок. Медиатека тянется по ширине и показывает файлы списком, плиткой или строкой.
- Подготовка файла за один проход ffmpeg: прокси H.264 720p (картинке — уменьшенная копия,
  звуку — m4a), миниатюры для таймлайна, пики звука.
- Дорожки: содержимое, наложения, звук. Элементы двигаются мышью, тянутся за оба края, прилипают
  к курсору и соседям, переносятся между дорожками; файл можно перетащить из списка на дорожку.
- Зазор на дорожке содержимого даёт чёрный кадр, наезд двух элементов — переход (9 видов `xfade`)
  с кроссфейдом звука.
- Наложения: картинка или видео поверх кадра — позиция, размер, поворот, прозрачность, фейды.
- Музыка: своя дорожка с громкостью и фейдами, микс со звуком видео при экспорте.
- Окно кадра: центр и зум, ключевые кадры с линейной интерполяцией. Тянуть по превью, крутить колесо.
- Ключевые кадры наложений (движение, размер, поворот, прозрачность) и цветокора (яркость, контраст,
  насыщенность, гамма).
- Отдаление: зум кадра от 0.2 (исходник уезжает вглубь, вокруг чёрные поля) до 8. Наложение
  масштабируется от 0.005 кадра — можно появиться точкой и вырасти на весь экран.
- Цвет: 6 пресетов и ручные яркость, контраст, насыщенность, гамма, сочность, резкость.
- Звук: шумодав, срез низов, компрессор, нормализация громкости по LUFS. Только при экспорте.
- Текст: 3 пресета, позиция, кегль, цвет, обводка, анимации «плавно» и «выскок».
- Субтитры: 3 стиля, вставка SRT или строк «старт конец текст», правка реплик прямо на таймлайне.
- Экспорт: 1080×1920 и другие размеры, 30/60 fps, H.264/H.265 через NVENC или libx264/libx265,
  прогресс по WebSocket.
- Отмена и повтор действий, горячие клавиши: пробел, стрелки, Home, S, K, Delete, Ctrl+Z/Y.

Превью и экспорт считают окно кадра одной и той же функцией (`src/shared/frame.ts`),
поэтому картинка в экспорте совпадает с превью.

## Запуск

Нужны Bun 1.3.14+ и ffmpeg 7.0+ (проверялось на 9.0.1). ffmpeg в поставку не входит.
Граф передаётся файлом через `-/filter_complex`, эта запись появилась в 7.0.

```
bun install
cp ki.config.example.json ki.config.json   # укажи папку с ffmpeg.exe
bun run dev
```

Откроется окно Edge/Chrome в режиме приложения. Без браузера в режиме приложения открывается
обычный браузер. Переменные окружения: `KI_FFMPEG_DIR`, `KI_PORT`, `KI_NO_WINDOW=1`.

## Проверки

```
bun run check      # типы (сервер и интерфейс отдельно) + тесты
```

Хук `.githooks/pre-commit` делает то же самое; включается `bun run hooks`.

## Сборка в exe

```
bun run build      # dist/ki-video.exe, консоль скрыта
```

В exe входят сервер, интерфейс и C-исходник для пиков. Рядом кладётся `ki.config.json`.

## Docker

```
docker build -t ki-video .
docker run -p 4777:4777 -v /path/to/videos:/media -v ki-data:/data ki-video
```

В контейнере нет системного диалога: файлы выбираются через просмотр папок или путь `/media/...`.

## Структура

```
src/shared   модель проекта, математика кадра, таймлайн, сборка ffmpeg-графа, ASS, пресеты
src/server   Bun.serve, поиск ffmpeg, ingest, экспорт, хранилища, окно, диалог
src/app      React: стор без библиотек, плеер на canvas, компоненты, стили
tests        bun test для общего кода
scripts      build.ts (кладёт ki.config.json рядом с exe)
.memories    заметки для агентов: состояние, решения, журнал
```

## Ограничения демо

- Цвет и звуковая цепочка задаются на весь проект, а не на элемент.
- В превью на наезде виден верхний элемент: сам переход появляется только в экспорте.
- Сочность и резкость по ключам не меняются: фильтры ffmpeg не принимают выражения по времени.
- Дальше 0.2 кадр не отдаляется: холст под ffmpeg растёт как 1/zoom. Для появления «из точки» —
  дорожка наложений.
- Гамма, сочность и резкость в превью не показываются (canvas умеет только brightness/contrast/saturate).
- Звуковая цепочка слышна только в экспорте.
- Распознавания речи нет: субтитры вставляются готовыми.
- Нативного окна у Bun нет, поэтому окно — это Edge или Chrome с флагом `--app`.
