## Смоук интерфейса (07.09.2026, Playwright, отдельная папка данных)

Импорт видео, картинки и mp3 → карточки с типами → элементы на дорожках → перенос картинки с наложений
на содержимое (прилип к концу видео) → растягивание за правый край → наезд, прижатый к половине
короткого элемента → два ключа наложения → два ключа цвета (в превью Ч/Б) → плитка и ширина медиатеки →
экспорт из панели за 2,8 с, 12 с 1080×1920 h264+aac. Кадры выходного файла проверены глазами.
Нативное перетаскивание файла из списка Playwright не воспроизводит: обработчик проверен
синтетическим `drop`.
