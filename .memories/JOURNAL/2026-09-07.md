# 07.09.2026 — старт проекта, техно-демо

## Разведка

- Bun 1.3.14 на машине. Отчёт по документации: нативного окна нет; `--compile` с `--windows-hide-console`,
  HTML-импорты внутри exe (с 1.2.17), `cc()` на Windows x64 (без `#include` стандартных заголовков).
- ffmpeg 8.1 (BtbN gpl) в `E:/Apps/ffmpeg/n81/...`: NVENC h264/hevc, CUDA, libass, afftdn, loudnorm, zoompan.
- Исходники: `E:/Videos/Counter-strike 2/*.mp4`, HEVC 1728×1080@60, AAC 48 кГц, ~30 с, ~25 МБ.
- Расширения HEVC в системе нет, значит прокси обязателен.

## Проверки до кода

- Граф `crop(x,y по t) → scale → ass → drawtext` с NVENC: 2 с на 2-секундный отрезок, кириллица есть.
- `sendcmd` на `crop w/h` — segfault. Заменено на `zoompan` с `it`: 120 кадров за 1,6 с.
- Полный граф из `buildExportPlan` на реальных файлах: exit 0, 3 с на 3 с вывода.

## Смоук через Playwright

Импорт по пути → подготовка 4,5 с → два клипа на таймлайне → ключи 2 с (1×) и 5 с (2×, сдвиг вправо) →
быстрый пресет → текст «ЛУЧШИЙ МОМЕНТ» → три реплики → воспроизведение → экспорт 60 с за 33,6 с.
Кадры выходного файла совпадают с превью.

## Починено по ходу

- Сетка `1fr` растягивалась по содержимому и прятала таймлайн: `minmax(0, 1fr)` и `min-height: 0`.
- Обратные слэши в `ki.config.json` ломали JSON: перешли на прямые, добавили понятную ошибку.
- DOM-типы перекрывали `ReadableStream` Bun: два tsconfig.
- Heredoc через Bash на Windows обрывался на длинных файлах: исходники писались инструментом Write.

## Exe

`bun run build` → `dist/ki-video.exe` 94 МБ. Запуск с `KI_NO_WINDOW=1`: статус ok, страница 200, подготовка
клипа 4,2 с. Первый прогон показал «peaks ts»: TinyCC не открыл `B:/~BUN/root/peaks-*.c`. Починено через
`type: "text"` + временный файл, второй прогон — «peaks C».

## Осторожно

При остановке dev-сервера через `Stop-Process` по имени `bun` и времени старта могли попасть чужие процессы bun
другого агента. Дальше гасить только по PID из `$!` или по имени `ki-video`.

## Ревью тремя агентами и правки

- Сервер (19 замечаний, 8 существенных): обход пути через `:id` → проверка формата id и наличия файла;
  нет проверки `Host`/`Sec-Fetch-Site` → `http/guard.ts` на всех маршрутах; гонка «один экспорт» → слот
  занимается до первого await; пик −32768 переполнял байт → clamp в C и TS; `Bun.isStandaloneExecutable`
  в 1.3.14 не определён → `Bun.embeddedFiles.length`; удаление файла во время подготовки → AbortController;
  `assets.json` пишется через tmp+rename по очереди; 416 для невыполнимых Range; чётная высота прокси.
- Общий код (13, 2 существенных): выражение до первого ключа экстраполировало → обёртка `if(lt(t,t0),v0,…)`;
  граф в аргументах мог превысить 32 767 символов → `-filter_complex_script graph.txt`; `crop … exact=1`;
  чётное окно в `baseWindow` общее для превью и экспорта; `hvc1` по кодеку; эпсилон ключей 8 мс.
- Интерфейс (18, 6 существенных): клик по клипу гасился родительской дорожкой → `stopPropagation`;
  перемотка при воспроизведении → `seek` через плеер; отмена после жеста → снимок до начала жеста;
  селектор `?? []` → стабильная константа; сохранение при закрытии вкладки (`pagehide`, keepalive);
  горячие клавиши по `e.code`; отдельный `Playhead`; компоненты по одному на файл.
- Итог: 46 тестов, повторный смоук: выделение, перемотка при воспроизведении, экспорт 17 с за 9,7 с.
