## Правила проекта

- Гейт: `bun run check` (tsc для сервера и интерфейса раздельно + `bun test`). Хук pre-commit делает то же.
- Одна математика кадра для превью и экспорта: `src/shared/frame.ts`. Менять только вместе с тестами.
- Новые зависимости не тянуть: сейчас только `react`, `react-dom`, `lucide-react` и типы.
- Импорты через алиасы `@shared/*`, `@server/*`, `@app/*`.
- Комментарии в коде на русском, не длиннее двух строк. Коммиты на английском: `type(scope): emoji message`.
- Не пушить. Только локальные коммиты в `develop`.
