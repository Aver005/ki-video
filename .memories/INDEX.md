## Правила проекта

- Гейт: `bun run check` (tsc для сервера и интерфейса раздельно + `bun test`). Хук pre-commit делает то же.
- Одна математика кадра для превью и экспорта: `src/core/frame.ts`. Менять только вместе с тестами.
- Зависимости добавлять только с разрешения. Сейчас: `react`, `react-dom`, `lucide-react`,
  `react-aria-components`, `cn`, `class-variance-authority`, `tw-animate-css`; в разработке —
  `tailwindcss`, `bun-plugin-tailwind`, `shadcn`.
- Импорты через алиасы, включая импорты внутри среза: `@core/*`, `@server/*`, `@app/*`, `@pages/*`,
  `@widgets/*`, `@features/*`, `@entities/*`, `@shared/*`.
- Интерфейс раскладывается по FSD: слой видит только слои ниже себя и `@core/*`. Вход в срез — `index.ts`.
- Компоненты интерфейса ставить через `bunx shadcn@latest add <имя>`, руками в `src/shared/ui` не писать.
  Эта папка выведена из-под `oxfmt`, чтобы `shadcn add --diff` продолжал работать.
- Комментарии в коде на русском, не длиннее двух строк. Коммиты на английском: `type(scope): emoji message`.
- Формат сообщений коммитов задан в `.trae/rules/git-commit-message.md`: тема
  `<type>(<scope>)!: <emoji> Description`, тело — разделы Keep a Changelog (`### Added`,
  `### Changed`, `### Removed`, `### Fixed`) со списками. Проверять по правилу, а не по памяти.
- Ветка `develop` публикуется в `origin` (github.com/Aver005/ki-video). Пушит заказчик, агент — нет.
  Историю не переписывать: она опубликована. Перед любой правкой истории смотреть `git log origin/develop`,
  а не полагаться на заметки.
