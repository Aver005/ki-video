# DECISIONS
> Решения с причинами. Last updated: 2026-09-07.

- `[DECIDED]` **Bun + браузерный интерфейс, ffmpeg как внешний процесс.** Bun даёт сервер, бандлер, тесты
  и `--compile` без зависимостей. Кодеки писать самим бессмысленно.
- `[DECIDED]` **Окно — Edge/Chrome `--app`.** Проверено по документации Bun 1.3.14: нативного окна нет,
  `Bun.WebView` умеет только headless. WebView2 через FFI — отдельная задача.
- `[DECIDED]` **Прокси H.264 720p всегда.** Исходники ShadowPlay в HEVC, в Chromium без расширения HEVC
  не играют. Прокси делает NVENC за ~3 с на 30 с клипа.
- `[DECIDED]` **Зум через zoompan после crop.** `crop` меняет w/h только через `sendcmd`, а это в ffmpeg 8.1
  падает с segfault (проверено). `zoompan` с `it` работает.
- `[DECIDED]` **React без UI-библиотек, стор на `useSyncExternalStore`.** Минимум зависимостей по
  требованию владельца; логика в `actions.ts`, компоненты только UI.
- `[DECIDED]` **Пики звука на C через `cc()`** как проба возможностей Bun; TS-путь остаётся запасным
  и эталонным в тестах. Исходник без `#include`, чтобы не зависеть от заголовков TinyCC на Windows.
- `[DECIDED]` **Пути в `ki.config.json` через прямые слэши.** Обратные ломают JSON.
- `[DECIDED]` **Один проект на приложение.** Для демо достаточно; менеджер проектов позже.
- `[DECIDED]` **Диалог файлов через PowerShell `OpenFileDialog`.** Нативно для Windows, без пакетов.
  В Docker и на Linux — просмотр папок через `/api/fs`.
- `[DECIDED]` **Граф ffmpeg передаётся файлом** (`-filter_complex_script`): командная строка Windows ограничена
  32 767 символами, а каждый ключевой кадр даёт до 7 повторов выражения.
- `[DECIDED]` **Локальный сервер защищён от чужих страниц**: Host только локальный, изменяющие запросы только
  с `Sec-Fetch-Site: same-origin`. Иначе любая вкладка могла бы запускать ffmpeg по своим путям.
