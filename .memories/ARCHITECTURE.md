# ARCHITECTURE
> Слои и поток данных. Last updated: 2026-09-07.

## Слои

```
src/shared  ← чистый код без Bun и DOM. Модель, математика, генераторы ffmpeg-аргументов и ASS.
src/server  ← Bun: процессы ffmpeg, файлы, HTTP/WS. Зависит от shared.
src/app     ← браузер: React, canvas. Зависит от shared. Сервер и интерфейс друг о друге не знают.
```

Типы для сервера и интерфейса проверяются раздельно (`tsconfig.json` с `bun-types`,
`tsconfig.app.json` с DOM), иначе DOM-типы ломают `ReadableStream` из Bun.

## Поток данных

1. Импорт: путь → `ffprobe` → `MediaAsset(processing)` → очередь по одному → один вызов `ffmpeg` с тремя
   выходами (прокси `proxy.mp4`, `thumbs/%04d.jpg`, `pcm.raw`) → пики → `ready`. Всё в `.ki-data/cache/<id>`.
   `id = hash(путь|размер|mtime)`: тот же файл повторно не готовится.
2. Проект: один `project.json`. Интерфейс держит копию в сторе, шлёт PUT с задержкой 400 мс.
3. Превью: `Player` держит `<video>` на каждый файл (прокси), рисует регион на canvas.
   Регион считает `frameToRegion` из `shared/frame.ts`; коэффициент прокси/исходник = `proxy.width / width`.
4. Экспорт: `buildExportPlan` собирает аргументы, сервер пишет `subs.ass` в папку задания, запускает
   ffmpeg с `-progress pipe:1`, события идут по WS.

## Кадр 9:16 из горизонтального видео

Базовое окно: вся высота исходника с пропорцией выхода. Ключевой кадр — центр `(cx, cy)` и `zoom ≥ 1`.
Регион = базовое окно / zoom вокруг центра, прижатый к границам.

В ffmpeg: `crop=W:H:x(t):y(t)` (crop умеет менять только x/y по кадрам) → `scale` до выхода →
`zoompan` с `z(it)`, `x(it)`, `y(it)`, если есть зум. Выражения — кусочно-линейные `if(lt(t,..),..)`.
`-ss/-t` стоят перед `-i`, поэтому `t` внутри клипа начинается с нуля.

## Текст и субтитры

Один ASS-файл на экспорт: стиль `Sub` из пресета, текстовые слои строками с `\pos`, `\fs`, `\c`, `\3c`.
Превью рисует то же на canvas (Arial, обводка `strokeText`). Совпадение не попиксельное.

## Окно приложения

У Bun нет нативного окна (`Bun.WebView` только headless). Запускаем Edge или Chrome с `--app=URL` и
отдельным `--user-data-dir` внутри `.ki-data`. Exe собирается с `--windows-hide-console`.
