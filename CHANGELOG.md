## [0.1.0] — 2026-09-07

### Added

- Модель проекта: клипы, ключевые кадры окна (центр + зум), цвет, звук, текст, субтитры, вывод.
- Общая математика кадра для превью и экспорта; таймлайн с последовательными клипами.
- Сборка ffmpeg-графа: crop с панорамой по `t`, scale, zoompan для зума по `it`, eq/vibrance/unsharp,
  highpass/afftdn/acompressor/loudnorm, concat, ass. Генератор ASS для текста и субтитров.
- Сервер на Bun.serve: HTML-импорт интерфейса, API файлов/проекта/экспорта, WebSocket событий,
  отдача прокси с Range, диалог выбора файлов через PowerShell, просмотр папок.
- Ingest за один проход ffmpeg: прокси H.264 720p, миниатюры, PCM; пики звука на C через `bun:ffi cc()`
  с запасным путём на TypeScript.
- Определение NVENC и CUDA с пробным кодированием; запасные libx264/libx265.
- Интерфейс на React 19 без UI-библиотек: медиатека, превью на canvas с жестами, транспорт,
  таймлайн с миниатюрами, волной и ромбами ключей, инспектор с шестью вкладками, отмена/повтор.
- Скрипт сборки exe (`bun build --compile`, консоль скрыта) и Dockerfile.
- Тесты общего кода: кадр, таймлайн, выражения, ASS, аргументы экспорта, субтитры.
