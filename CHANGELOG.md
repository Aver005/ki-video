# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версии: [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Added

- Дорожки: содержимое, наложения и звук; элементы стоят на общей шкале со свободным размещением,
  зазоры заполняются чёрным.
- Переходы между элементами дорожки содержимого: наезд даёт `xfade` и кроссфейд звука, тип выбирается
  из девяти.
- Наложения: картинка или видео поверх кадра с позицией, размером, поворотом, прозрачностью и фейдами.
- Картинки и звуковые файлы как исходники: своя подготовка, длительность картинки задаёт элемент.
- Дорожка музыки: громкость и фейды на элемент, микс всех дорожек при экспорте.
- Таймлайн: перенос элементов мышью, растягивание за оба края, прилипание к курсору и краям соседей,
  перенос между дорожками, перетаскивание файла из списка на дорожку, скрытие и заглушение дорожек.
- Субтитры: реплики двигаются и тянутся на таймлайне, выделенная правится в инспекторе.
- Тянущиеся границы: ширина инспектора и высота таймлайна запоминаются.

### Changed

- Проект перешёл на версию 2; старый файл переносится на дорожки при загрузке (`shared/normalize.ts`).
- Инспектор: вкладка «Элемент» вместо «Кадр» и «Текст», свойства зависят от того, что выделено.
- Превью показывает наложения и играет музыку; время ведут часы, когда под курсором картинка или зазор.
- Граф передаётся ffmpeg через `-/filter_complex`: `-filter_complex_script` убрали в ffmpeg 9.
  Требуется ffmpeg 7.0+.

## [0.1.0] — 2026-09-07

### Added

- Модель проекта: клипы, ключевые кадры окна (центр + зум), цвет, звук, текст, субтитры, вывод.
- Общая математика кадра для превью и экспорта; таймлайн с последовательными клипами.
- Сборка ffmpeg-графа: crop с панорамой по `t`, scale, zoompan для зума по `it`, eq/vibrance/unsharp,
  highpass/afftdn/acompressor/loudnorm, concat, ass. Генератор ASS для текста и субтитров.
- Сервер на Bun.serve: HTML-импорт интерфейса, API файлов/проекта/экспорта, WebSocket событий,
  отдача прокси с Range, диалог выбора файлов через PowerShell, просмотр папок.
- Ingest за один проход ffmpeg: прокси H.264 720p, миниатюры, PCM; пики звука на C через `bun:ffi cc()`
  с запасным путём на TypeScript.
- Определение NVENC и CUDA с пробным кодированием; запасные libx264/libx265.
- Интерфейс на React 19 без UI-библиотек: медиатека, превью на canvas с жестами, транспорт,
  таймлайн с миниатюрами, волной и ромбами ключей, инспектор с шестью вкладками, отмена/повтор.
- Скрипт сборки exe (`bun build --compile`, консоль скрыта) и Dockerfile.
- Тесты общего кода: кадр, таймлайн, выражения, ASS, аргументы экспорта, субтитры.
